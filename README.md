# Commodore Computers on PS5

Justin's Commodore emulators from the Waveshare ESP32-P4 board (`WaveshareP4_C64Amiga`), as PS5
homebrew apps.

| | |
| --- | --- |
| [`c64/`](c64/README.md) | **Commodore 64** - joystick on the DualSense, the C64 keyboard on screen, programs (`.prg`) and disks (`.d64`) from a menu |
| `amiga/` | Amiga 500 - next |

Built with the [PS5 homebrew starter](https://github.com/MiladRTX/ps5-homebrew-starter)'s kit and the
PS5 payload SDK v0.42, as NUCLEAR MISSION is. See `c64/README.md` to build and install.
